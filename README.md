## 📖 Visão Geral

A **Plataforma CEFET-RJ 2027** é uma solução educacional e tecnológica desenvolvida para apoiar estudantes na preparação para o concorrido exame de admissão ao **Ensino Médio Técnico Integrado do CEFET-RJ (Campus Maracanã)**. O projeto foi construído por entusiasmo por tecnologia e estudos, com conteúdos estruturados a partir das diretrizes da **BNCC**, dos editais oficiais e com apoio de agentes de IA.

O processo seletivo do CEFET-RJ é conhecido pelo rigor técnico de sua prova e pelo perfil conceitual das questões: **a banca pune severamente a decoreba mecânica** e premia candidatos capazes de interpretar textos complexos, raciocinar logicamente e conectar os conceitos científicos a problemas da vida real.

Esta plataforma foi construída sob a premissa da **democratização do ensino de excelência**:
- **100% Gratuita e de Código Aberto:** Sem mensalidades, sem paywalls e sem anúncios.
- **Zero Atrito Técnico:** Arquitetura *pure vanilla* que dispensa instalações complexas, funcionando imediatamente em qualquer computador, tablet ou smartphone.
- **Privacidade & Autonomia:** Progresso, anotações e simulados salvos localmente via `localStorage`, sem rastreamento nem necessidade de login obrigatório.

## 🧠 Pilares Didáticos: Método Anti-Decoreba

A espinha dorsal metodológica do projeto baseia-se no método didático **EBAC**, alinhado às diretrizes da BNCC e nos princípios da neurociência da aprendizagem (*Active Recall*, *Spaced Repetition* e *Dual Coding*), desenvolvido em conjunto com agentes de IA:

```
                        ┌──────────────────────────────────────────────┐
                        │          MÉTODO DIDÁTICO EBAC                │
                        └──────────────────────┬───────────────────────┘
                                               │
     ┌──────────────────────┬──────────────────┴─────────────────┬──────────────────────┐
     ▼                      ▼                                    ▼                      ▼
┌──────────────┐    ┌──────────────┐                     ┌──────────────┐       ┌──────────────┐
│      E       │    │      B       │                     │      A       │       │      C       │
│ Entendimento │    │     Base     │                     │  Aplicação   │       │ Consolidação │
│  Conceitual  │    │      &       │                     │   Prática    │       │      &       │
│  (O Porquê)  │    │ Nivelamento  │                     │ (Cotidiano)  │       │ Metacognição │
└──────────────┘    └──────────────┘                     └──────────────┘       └──────────────┘
```

### Os 4 Pilares EBAC

1. **`E` — Entendimento Conceitual:** Antes de fórmulas ou regras gramaticais, o aluno aprende a gênese histórica do conceito: *qual problema da humanidade motivou aquela descoberta?*
2. **`B` — Base & Nivelamento:** Resgate acolhedor e dinâmico de pré-requisitos do 6º ao 9º ano da BNCC. Elimina a sensação de inadequação frequentemente sentida por alunos que tiveram defasagens escolares.
3. **`A` — Aplicação Prática & Analogia Visual:** Tradução de abstrações para analogias do mundo físico e da cultura pop, demonstrando como a matéria se manifesta em tecnologia, indústria e cotidiano.
4. **`C` — Consolidação & Metacognição:** Exercícios com diagnósticos linha a linha de alternativas corretas e incorretas, forçando o estudante a verbalizar e justificar a lógica da resposta.

## ⚡ O Player Ativo de 5 Etapas *(Benchmark Brilliant.org)*

Cada um dos módulos curriculares da plataforma é estruturado no formato de **Player Interativo de 5 Etapas**, desenhado para manter o engajamento dopaminérgico em níveis ideais:

| Etapa | Ícone | Foco Cognitivo | Descrição |
|:---|:---:|:---|:---|
| **1. O que é e por que importa** | 🏛️ | Contextualização Histórica | Revela a origem prática do conceito (ex: egípcios dividindo terras com frações). |
| **2. A Grande Sacada** | 💡 | Analogia Intuitiva | Cria uma âncora mnemônica poderosa que elimina o medo do conteúdo abstrato. |
| **3. Teoria Descomplicada** | 🔬 | Rigor Conceitual Claro | Apresenta a teoria com linguagem direta, esquemas visuais e fórmulas passo a passo. |
| **4. Desafio Guiado** | 🎯 | Resolução Orientada | Problema clássico do estilo CEFET destrinchado com todas as etapas lógicas expostas. |
| **5. Treino Ativo Imediato** | ❓ | Fixação Ativa com Feedback | Questão de teste com resposta comentada em tempo real para cada uma das opções (A, B, C, D). |

## 🎯 As 3 Trilhas de Aprendizagem

Para atender a estudantes em diferentes estágios de preparação, a plataforma disponibiliza três roteiros dinâmicos:

| Trilha | Público-Alvo | Carga Horária | Filosofia & Foco |
|:---|:---|:---:|:---|
| 🚀 **Trilha Seleção** | Alunos com boa base que precisam de foco cirúrgico no edital | ~35 horas | Prioriza os tópicos de maior peso e incidência nas últimas provas do CEFET-RJ. |
| 🛡️ **Trilha Reforço** | Alunos que enfrentaram defasagens no Ensino Fundamental II | ~20 horas | Nivelamento estruturado com a base da BNCC (frações, geometria intuitiva, gramática base). |
| ⚡ **Trilha Híbrida / Completa** | Roteiro de alta performance para quem busca os primeiros lugares | ~55 horas | Cobertura integral dos 64 módulos pedagógicos, unindo nivelamento e aprofundamento. |

## ⚡ Central de Preparação & Simulados Multi-Modalidades

Para maximizar a retenção e a adaptação ao formato real do exame do CEFET-RJ, a plataforma dispõe de 6 ferramentas integradas na aba **Preparação**:

1. **🎯 Simulado Oficial Completo (30 Questões):**
   - Proporção exata das disciplinas do certame (Língua Portuguesa, Matemática, Física, Química, Biologia, História e Geografia).
   - Cronômetro regressivo oficial de 4 horas com alerta sonoro/visual de encerramento.
   - Espaço integrado de Rascunho de Redação com contador de linhas e dicas de estrutura dissertativa.
   - Relatório completo com gabarito oficial e explicação detalhada para cada alternativa.

2. **🏛️ Provas Anteriores Oficiais (2023 a 2026):**
   - Cadernos completos das edições anteriores do CEFET-RJ com base nos editais da banca Selecon:
     - **CEFET-RJ 2026** (Edital Selecon 06/2025): 30 questões objetivas oficiais + proposta de Redação sobre Inteligência Artificial e Ética.
     - **CEFET-RJ 2025** (Edital Selecon 07/2024): 30 questões objetivas oficiais + proposta de Redação sobre Biodiversidade e Sustentabilidade.
     - **CEFET-RJ 2024** (Edital Selecon 08/2023): 30 questões autênticas completas + proposta oficial de Redação sobre "Impactos do uso excessivo da tecnologia nos jovens brasileiros".
     - **CEFET-RJ 2023** (Edital Selecon 09/2022): 40 questões autênticas completas (10 Português, 10 Matemática, 10 Natureza, 10 Humanas).
   - **Cronômetro de 4 Horas Oficial:** Relógio regressivo contínuo com avisos graduais (amarelo aos 30 minutos e vermelho crítico aos 10 minutos).
   - **Interface Intuitiva de Resolução:** Mapa dinâmico de questões (respondidas vs. pendentes), seleção instantânea de alternativas, filtro por disciplina e gaveta de rascunho de redação em tempo real.
   - **📥 Baixar Caderno da Prova (PDF/Impressão):** Geração instantânea de caderno diagramado no padrão oficial para resolução impressa ou salvamento em PDF.
   - **📥 Baixar Gabarito Oficial:** Exportação da grade oficial de respostas da Selecon e comentários explicativos para correção autônoma.
   - Integração completa com o **Caderno de Erros Inteligente** (registra apenas itens errados, ignorando respostas em branco) e o **Histórico de Desempenho**.

3. **⚡ Desafio Sprint (Gestão de Ritmo — 2m30s por questão):**
   - 5 questões sorteadas com limite rígido de 150 segundos por questão.
   - Treino voltado a tomada rápida de decisão e gestão do tempo de prova.
   - Cronômetro interativo com alerta de urgência e diagnóstico de ritmo ao final.

4. **📚 Baterias Temáticas por Disciplina:**
   - Permite treinar blocos específicos da matéria em que o aluno identifica maior defasagem.
   - Feedback e resolução comentada imediatos após cada resposta.

5. **📓 Caderno de Erros Inteligente (Reteste Ativo):**
   - Registra de forma autônoma apenas as questões que o estudante errou (desconsiderando itens deixados em branco).
   - Permite retestar as lacunas de conhecimento sem poluição visual.
   - Opções de marcar o item como resolvido ou removê-lo individualmente do caderno de erros.

6. **📊 Histórico de Simulados & Evolução:**
   - Armazenamento local das tentativas de simulados, provas anteriores e desafios sprint.
   - Estatísticas de aproveitamento geral, média de acertos e comparativo com o histórico de corte.

### Decisões Arquiteturais Fundamentais

1. **Zero Dependencies & Zero Build Tools:**
   - **Por que sem React/Vue/Svelte/Tailwind Build?** Em contextos de vulnerabilidade socioeconômica, muitos estudantes utilizam conexões de dados limitadas (3G/4G pré-pago) e dispositivos modestos. A aplicação carrega em **menos de 100 milissegundos**, sem a necessidade de baixar bundles pesados de JavaScript.
2. **Apple Liquid Glass Aesthetic:**
   - Superfícies translúcidas com `backdrop-filter: blur(32px) saturate(200%)`.
   - Borda hiperfina com relevo superior de luz (`inset 0 1px 0 rgba(255, 255, 255, 0.38)`).
   - Paleta de cores escura inspirada em temas espaciais e modo claro de alto contraste para leitura à luz do dia.
3. **Tipografia Bespoke:**
   - **Títulos & Display:** [Outfit](https://fonts.google.com/specimen/Outfit) — Modernidade geométrica, legibilidade em telas e autoridade visual.
   - **Corpo & Interface:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) — Desenhada especificamente para alta legibilidade em microinterfaces e parágrafos longos.
4. **Física & Interações Hápticas:**
   - Efeito táteis suaves ao clique (`active:scale-[0.98]`).
   - Transições cinéticas com curva de desaceleração natural: `cubic-bezier(0.16, 1, 0.3, 1)`.

## 🚀 Como Executar Localmente

Como o projeto é construído em **Web Standards puros**, você não precisa instalar Node.js, NPM ou qualquer ferramenta de empacotamento:

### Método 1: Execução Direta (Mais Rápido)
Basta clonar o repositório e dar um duplo clique no arquivo `index.html`:
```bash
git clone https://github.com/webglossdev/CEFET.git
cd CEFET
# Abra index.html no seu navegador favorito (Chrome, Firefox, Edge, Safari)
```

### Método 2: Servidor Local Python
```bash
python -m http.server 8000
# Acesse no navegador: http://localhost:8000
```

### Método 3: VS Code Live Server
1. Abra a pasta do projeto no **Visual Studio Code**.
2. Clique com o botão direito em `index.html`.
3. Selecione **"Open with Live Server"**.

### Método 4: Deploy no GitHub Pages (1 Clique)
1. Vá até as **Configurações (Settings)** do repositório no GitHub.
2. Na aba lateral, clique em **Pages**.
3. Em *Source*, selecione a branch `main` e a pasta `/ (root)`.
4. Clique em **Save**. O site estará no ar gratuitamente em instantes!

Contribuições são muito bem-vindas! Seja para adicionar novas questões ao simulador, sugerir analogias didáticas mais intuitivas ou relatar inconsistências:
